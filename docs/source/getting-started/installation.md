# Installation

## Requirements

EtherLyzer requires Python 3.14 or newer.

## Install from PyPI

Install EtherLyzer with pip:

```shell
pip install etherlyzer
```

Upgrade an existing installation:

```shell
pip install -U etherlyzer
```

Verify the installation:

```shell
etherlyzer --version
```

or:

```shell
etherlyzer -v
```

## Developer installation

Clone the repository and install the development environment with Poetry:

```text
git clone https://github.com/blue-hexagon/EtherLyzer
cd EtherLyzer
poetry install
```

Run EtherLyzer inside the Poetry environment:

```shell
poetry run etherlyzer --version
```
