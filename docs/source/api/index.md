# API Reference

EtherLyzer can be used directly as a Python library in addition to its command-line interface.

The library provides functionality for:

- IEEE registry management,
- lookup indexes,
- vendor correlation,
- MAC validation and normalization,
- MAC formatting, and
- registry synchronization.

The command-line interface is built on the same underlying library functionality.

:::{note}
The public Python API is currently being documented.

Detailed module, class, and function references will be added as the public API is formalized.
:::
